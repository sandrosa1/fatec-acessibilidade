# Projeto base para aula de Acessibilidade

## Atividade 1

### Melhorar a usuabilidade para quem tem baixa visão

- 1- Criar dois botões: um para aumentar a fonte e outro para diminuir.
- 2- Escolher o melhor local para posicionar os botões.
- 3- Encontrar uma maneira de selecionar todas as fontes para que, quando o botão for acionado, o tamanho seja alterado.
- 4- Determinar o quanto a fonte deve aumentar ou diminuir a cada clique.
- 5- Definir um tamanho máximo e mínimo para as fontes.
- 6- Criar uma forma de aplicar essa funcionalidade.
